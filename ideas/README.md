# 🌱 アイデア一覧

このフォルダは、検討が進んだアイデアを Markdown で整理する場所です。

思いつきの段階では、まず [GitHub Issues](../issues) に記録してください。必要に応じて [アイデア詳細テンプレート](../templates/app-idea.md) をコピーし、`ideas/<idea-slug>.md` として保存します。

## 管理のルール

- **1アイデア = 1 Issue** を基本にする
- 詳細ファイルを作ったら、元の Issue の URL を記載し、Issue 側からもリンクする
- アイデアの名前や機能は、検討しながら自由に変更してよい
- アプリとして独立したら、新しいリポジトリへのリンクを追加する
- このリポジトリは公開されているため、個人情報や秘密鍵などは記録しない

## ステージの目安

| ステージ | 意味 |
| --- | --- |
| 🌱 Seed | まずは思いつきを記録 |
| 🌿 Exploring | 課題・利用者・実現方法を調べる |
| 🪴 Planned | 作る範囲や最初の機能が見えている |
| 🚀 Building | 開発中 |
| 🌸 Shipped | 公開済み |

ステージは進んだり戻ったりして構いません。
